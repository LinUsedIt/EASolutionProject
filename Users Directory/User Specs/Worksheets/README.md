# Worksheets

Inputs worksheets for Spec Driven Approach B, one per phase or topic, named
`<Phase> - <Topic> - Worksheet.<ext>`. Laufey creates them with the known
facts pre-filled and an explanation of each document and section. Fill in
the answer areas, save here, and set `status: ready` in the frontmatter.
Laufey does not edit your answers. See `.claude/skills/spec-driven/SKILL.md`.
