# Assignments: what the professor has asked for

The record of everything Sir Pira has asked for: requirements, deadlines,
format, and feedback. Laufey updates this with `/log-assignment` whenever
someone relays something from the professor, and checks it before any
planning, drafting, or reviewing. Rules: `.claude/rules/assignments.md`.

## Entry format

```
### A<n>: <Short title>

- **Status:** Not started / In progress / Submitted / Graded / Revising
- **Deadline:** YYYY-MM-DD, or Unknown
- **Source:** who relayed it, when (YYYY-MM-DD), and from where
  (class, chat, file path)
- **Requirements:**
  - one bullet per requirement, in the professor's wording where it matters
- **Format / submission:** how it should be delivered, if specified
- **Feedback from the professor:**
  - YYYY-MM-DD: what he said
- **Open questions:**
  - anything to clarify with the professor
- **Team files:** where the team's work for it lives
```

Newest active assignment first. Move an assignment to **Completed** once
it's graded and nothing more is expected.
