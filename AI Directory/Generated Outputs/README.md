# Generated Outputs

Everything Laufey generates goes here: analyses, reviews, summaries,
plans, drafts, and revised or compiled versions of the team's work. Name
dated files `YYYY-MM-DD - Title.ext`.

Two kinds of output go elsewhere:

- Study guides go in `Course Files/Study Guides/`.
- Concept explanations go in `Course Files/AI Explanations/`.

See `.claude/rules/file-placement.md`.
