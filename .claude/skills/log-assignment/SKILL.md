# Log what the professor asked for

`AI Directory/Assignments.md` is the record of everything the professor
has asked for. Read it before changing it.

## 1. Find or create the assignment

- If what was said belongs to an existing assignment (same piece of work,
  a new requirement, a changed deadline, feedback on a submission),
  update that entry.
- Otherwise create a new entry with the next number (`A1`, `A2`, `A3`,
  ...), in the exact format shown at the top of the file. New entries go
  at the top of **Active**.
- If you can't tell which it is, ask.

## 2. Fill it in carefully

- **Source:** who relayed it, when, and where it came from (class, group
  chat, a file in `Users Directory/Course Assignments/`).
- **Deadline:** an absolute date. If it was given as "next Friday", work
  out the date from when it was said. If it's unknown, write `Unknown`
  and add it to open questions.
- **Requirements:** one bullet each. Keep the professor's wording when it
  matters, and quote it if it's exact. Don't soften or tighten anything.
- **Feedback:** anything the professor said about submitted work, dated.
- **Open questions:** anything unclear, for the team to ask the professor.
- **Status:** one of `Not started`, `In progress`, `Submitted`, `Graded`,
  or `Revising`.
- Never invent a requirement to fill a gap.

## 3. Check for conflicts

If the new information contradicts what's already recorded (a different
deadline, a requirement that changed), don't overwrite it silently.
Point out the conflict, ask which is current, and record the change with
its date.

## 4. Finish

- When an assignment is graded and nothing more is expected, move it to
  **Completed** and collapse it to a few lines. Keep the professor's
  feedback, since later work often builds on it.
- Confirm in one line what you saved, for example: "Saved to A3: deadline
  2026-10-23, two new format requirements."
