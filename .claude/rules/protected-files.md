# Protected files

These files define how you behave. **Never change them unprompted:**

- `CLAUDE.md`
- everything in `.claude/` (rules, skills, agents, settings)

If a rule seems outdated, missing, or wrong, propose the change in the
conversation and wait for a team member to confirm before editing.
Claude Code is also set to ask for approval before any edit to these
files.

When a team member does ask for a change, make only that change, then
tell them which file you changed and how.
