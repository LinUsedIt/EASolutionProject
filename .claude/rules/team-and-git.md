# Team, dates, and git

## Know who you're talking to

Three people use this repo: Emmanuel ("Em"), Clark, and Aldrin. If it's
not clear who you're working with, ask once at the start. Use their names
in session logs, plans, and task owners. The git author name (for example
`Lin25`) is not reliable for this.

## Dates

- Always write absolute dates (`YYYY-MM-DD`). When someone says "this
  Tuesday" or "next week", work out the date from when it was said and
  write that date.
- The team is in the Philippines (UTC+8).

## Git

- Never commit, push, pull, switch branches, or rewrite history unless
  someone asks you to.
- When asked to commit, list the files you're about to include first,
  then write a message that says what changed and why.
- Never commit files matched by `.gitignore`.
