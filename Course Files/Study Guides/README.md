# Study Guides

Chapter-by-chapter study guides for *Mastering the TOGAF Standard* (Eric
Jager, 2025). Laufey writes them with `/make-study-guide` using a fixed
template (`.claude/skills/make-study-guide/template.md`), so they all
share the same structure: Overview, Detailed Section Breakdown, Key Terms &
Definitions, Figures & Tables Referenced, and Self-Check Questions, with
page references throughout.

## Where each guide goes

| Chapters | Folder |
|---|---|
| 1–7 | `TOGAF Ch1-7/` |
| 8–9 | `TOGAF Ch8-9/` |
| 10–12 | `TOGAF Ch10-12/` |
| Other | Ask before creating a new folder |

The file name is `Chapter N - Chapter Title - Study Guide.<ext>`, in plain
ASCII. The compiled guide for all chapters is
`Mastering the TOGAF Standard - Compiled Study Guide (Ch 1-12).pdf`.
